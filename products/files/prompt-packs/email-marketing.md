# Email Marketing Prompts

## 1. Cold Outreach

```
Write a cold outreach email for [PRODUCT/SERVICE] targeting [AUDIENCE]. The email should:
- Open with a personalized observation about their business
- Identify a specific pain point we can solve
- Present our solution in 2-3 sentences
- Include a clear call-to-action
- Be under 150 words
- Sound human, not salesy

Context:
- Target: [DECISION_MAKER_TITLE] at [COMPANY_TYPE]
- Pain Point: [SPECIFIC_PAIN]
- Our Solution: [SOLUTION_NAME] that [KEY_BENEFIT]
```

## 2. Welcome Sequence

```
Write a welcome email sequence for new subscribers who signed up for [LEAD_MAGNET]. The sequence should:

Email 1 (Immediately): Deliver the lead magnet + set expectations
Email 2 (Day 2): Share the #1 tip related to [TOPIC]
Email 3 (Day 4): Tell the story of how we help [TARGET_AUDIENCE] achieve [RESULT]
Email 4 (Day 7): Social proof + case study
Email 5 (Day 10): Soft pitch for [PRODUCT]

Tone: [Friendly/Professional/Casual]
Length: 100-200 words each
```

## 3. Subject Line Generator

```
Generate 10 email subject lines for [CAMPAIGN_TYPE] promoting [PRODUCT] to [AUDIENCE].

Rules:
- Mix curiosity, urgency, and benefit-driven
- Keep under 50 characters
- Avoid spam trigger words
- Include at least 2 with emojis
- Test for mobile preview (30 chars)

Product: [PRODUCT_NAME]
Key Benefit: [MAIN_BENEFIT]
Audience: [TARGET_AUDIENCE]
```

## 4. Abandoned Cart Recovery

```
Write a 3-email abandoned cart sequence for [PRODUCT] priced at [PRICE].

Email 1 (1 hour): Reminder + product image + direct CTA
Email 2 (24 hours): Address objections + social proof
Email 3 (72 hours): Urgency + discount offer [X%]

Tone: Helpful, not pushy
Objections to address: [COMMON_OBJECTIONS]
```

## 5. Re-engagement Campaign

```
Write a re-engagement email for subscribers who haven't opened emails in [TIME_PERIOD].

Goal: Get them to re-opt-in or clean the list
Approach: [Win-back/Last-chance/Preference-center]
Incentive: [DISCOUNT/FREE_CONTENT/NONE]
```

## 6. Case Study Email

```
Write a case study email showcasing how [CUSTOMER] achieved [RESULT] using [PRODUCT].

Structure:
- Hook: The result in numbers
- Before: Their situation before
- Solution: What they implemented
- After: Quantified results
- CTA: Reader's next step

Customer: [NAME_COMPANY]
Result: [SPECIFIC_METRIC]
Industry: [INDUSTRY]
```

## 7. Product Launch

```
Write a product launch email for [PRODUCT_NAME] launching on [DATE].

Sections:
- Problem: What keeps your audience up at night?
- Solution: Introduce the product naturally
- Features: Top 3 benefits (not features)
- Social proof: Testimonial or beta user result
- Offer: Launch pricing + deadline
- FAQ: Top 3 objections answered

Audience: [TARGET]
Price: [PRICE]
Launch offer: [EARLY_BIRD_DISCOUNT]
```

## 8. Testimonial Request

```
Write a testimonial request email for customers who purchased [PRODUCT] on [DATE].

Goal: Get a specific, detailed testimonial
Ask for: Before/after, specific results, recommendation
Make it easy: Provide 3 questions to answer
Incentive: [YES/NO - if yes, describe]

Tone: Appreciative, low-pressure
```

## 9. Upsell/Cross-sell

```
Write an upsell email to existing customers of [CURRENT_PRODUCT] for [UPGRADE_PRODUCT].

Context: They've been a customer for [TIME]
Upgrade benefit: [SPECIFIC_ADVANTAGE]
Pricing: [PRICE] (show savings vs new purchase)
```

## 10. Newsletter Introduction

```
Write the first newsletter issue after someone subscribes to [NEWSLETTER_NAME].

Goal: Deliver value + set expectations for future issues
Include:
- One actionable tip
- One resource recommendation
- Personal note from the founder
- CTA to reply with their biggest challenge

Frequency: [WEEKLY/BIWEEKLY]
Topic: [NEWSLETTER_TOPIC]
```

## 11. Partnership Proposal

```
Write a partnership proposal email to [COMPANY] for [PARTNERSHIP_TYPE].

Goal: Start a conversation about mutual benefit
Structure:
- Why them specifically
- What we bring to the table
- What's in it for them
- Specific next step
```

## 12. Event Invitation

```
Write an event invitation for [EVENT_TYPE] on [DATE] about [TOPIC].

Event details:
- Format: [VIRTUAL/IN-PERSON]
- Duration: [LENGTH]
- Speaker: [IF_APPLICABLE]
- Value proposition: What attendees will learn

Create urgency without being pushy
```

## 13. Webinar Promotion

```
Write a webinar promotion email for [WEBINAR_TITLE].

Goal: Drive registrations
Key takeaways: [3_THINGS_ATTENDEES_WILL_LEARN]
Speaker credentials: [WHY_TRUST_THEM]
Urgency: [LIMITED_SEATS/DATE_DEADLINE]
```

## 14. Customer Anniversary

```
Write a customer anniversary email for [CUSTOMER] on their [ANNIVERSARY] with us.

Goal: Strengthen relationship + reduce churn
Include:
- Reflection on their journey
- Stats: What they've achieved
- Exclusive offer/insight
- Personal thank you
```

```
Write a referral request email to satisfied customers of [PRODUCT].

Goal: Generate referrals from happy customers
Incentive: [REFERRAL_REWARD]
Make it easy: Shareable link + pre-written message
```
